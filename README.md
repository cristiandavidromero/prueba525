# 📋 Formulario de Contacto en Angular

Este proyecto es un formulario de contacto desarrollado en **Angular 21.1.1** que incluye funcionalidades CRUD, validaciones reactivas, filtros y notificaciones tipo toast.

ejecutar npm install para bajar las dependencias.

---

## 🚀 Tecnologías utilizadas

- Angular (Standalone Components)
- TypeScript
- RxJS
- Reactive Forms
- ngx-toastr
- HTML / CSS

---

## 📌 Funcionalidades

### 🧾 Formulario
- Crear usuarios
- Editar usuarios
- Validaciones en tiempo real
- Validación de mayoría de edad
- Campos dinámicos según país

### 🌍 Lógica dinámica
- Mostrar/ocultar departamento y ciudad según país
- Reset del formulario con valores por defecto
- Normalización de datos entre API y formulario

### 📊 Tabla de datos
- Listado de usuarios
- Filtro por nombre o email
- Ordenamiento por columnas
- Edición desde la tabla

### 🔔 Notificaciones
- Toast de éxito al crear usuario
- Toast al actualizar usuario
- Mensajes automáticos con ngx-toastr

---

## 📱 Responsive
- Diseño adaptable a dispositivos móviles
- Ocultamiento de columnas no esenciales en pantallas pequeñas
